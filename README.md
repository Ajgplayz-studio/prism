# prism 
Prism is a OPEN SOURCE Discord alternative that has premium features for free.
 ## How to host your own version
 step 1: Fork the project. 
 Step 2: Add your changes. 
 Step 3: Click settings. 
 Step 4: Click pages. 
 Step 5: Change the branch from `none` to `main`. 
 Step 6: Hit Save and wait until it is deployed. 
 Step 7: when its done it will save as [your-username].github.io/[what you named your repository]

 ### example
 if my username was jeff
 and I named the repository as opencord
 the link would be https://jeff.github.io/opencord
