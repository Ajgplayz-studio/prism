# ◈ Prism

**Prism** is an open-source Discord alternative where everything is free — no Nitro, no paywalled features, just chat.

## Features

- 💬 Real-time messaging with channels
- 🏠 Create your own servers
- 📩 Direct messages between friends
- 👥 Online member list and typing indicators
- 🔐 Username + password accounts
- 🆓 100% free, forever

## Host your own

1. **Fork** this repository.
2. Make your changes (optional).
3. Go to **Settings → Pages**.
4. Change the branch from `none` to `main` and hit **Save**.
5. Wait for it to deploy — your site will be live at `https://[your-username].github.io/[repo-name]`.

### Example

If your username was `jeff` and you named the repository `opencord`, your site would be:

**https://jeff.github.io/opencord**

## Built with

- Firebase Authentication & Realtime Database
- Plain HTML, CSS and JavaScript — no frameworks, no build step
